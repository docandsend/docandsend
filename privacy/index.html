Who operates this site

This website is operated by Doc & Send Mobile Notary. Phone: 615-484-2552. Email: docandsendnotary@gmail.com.

Your choice comes first

No tracking, analytics, or third-party script is loaded when a page opens. A banner offers two choices with equal weight:

  • Accept allows the optional tawk.to chat widget to load.
  • Reject keeps third-party scripts off.

The choice is stored in this browser under the versioned localStorage key ds-consent-v1. The stored value is the choice (accept, reject, or chat), a version number, and a timestamp. It is not sent to Doc & Send. Cookie settings in the footer opens the banner again so the choice can be changed. Choosing again replaces the stored value. If the key version changes in a future update, the banner is shown again.

Until a choice is stored, a Chat with us button is shown with the phone number and email. Selecting Chat with us stores chat-only consent and loads the chat widget. It does not turn on other optional tools. Reject still keeps the widget off on later visits.

Chat widget (tawk.to)

Live chat is provided by tawk.to, a third party. The widget is requested from embed.tawk.to only after Accept, or after Chat with us. It is not on the page before that. Most pages use one tawk.to widget. One service page uses a different tawk.to widget. Messages typed into the widget are handled by tawk.to under its own terms. Counsel should review tawk.to's privacy policy and the California Invasion of Privacy Act (CIPA) before this wording is published. This draft does not state that tawk.to is or is not a CIPA problem. It only states when the script is allowed to load.

Fee calculator

The fee calculator runs in the browser. Signature count and the evening, weekend, and hospital add-on boxes stay on the device. If a service address is entered and Calculate is pressed, that address is sent to OpenStreetMap Nominatim (nominatim.openstreetmap.org) to estimate distance from downtown Nashville. The travel-fee note on the calculator still applies: within 30 miles the travel fee is $40; beyond 30 miles it is $40 plus $0.45 per extra mile. This website does not store the address. The distance lookup is part of using the calculator. It is not a script that loads when the page opens, and it is not an advertising tag.

Forms

This website does not include a form that submits information to Doc & Send. There is no account, newsletter signup, or contact form. To reach the business, use the phone number or email above, the optional chat widget after consent, or a Schedule button. Schedule buttons leave this website and open Calendly (calendly.com). Calendly is not embedded here and does not load with the page.

Google Consent Mode

Each page sets Google Consent Mode v2 defaults to denied for ad storage, ad user data, ad personalization, analytics storage, functionality storage, and personalization storage. Security storage is granted. This is a helper in the page itself. This website does not load Google Analytics, Google Tag Manager, or any other Google tag. Accept updates those helper signals to granted. That update does not send data to Google, because no Google tag is installed. Reject, and chat-only consent, leave the signals denied.

Fonts and other third parties

Pages use the device's system fonts. Google Fonts are not used. The audit found no map embed, advertising pixel, or analytics script on these pages. The only third-party script that the site is written to load is tawk.to, and only after the choices described above.
